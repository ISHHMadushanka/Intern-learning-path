# Intern Path

A site of study paths for **developer**, **QA**, **business analyst**, and **DevOps** interns. Interns open a role link; they do not get the website source code.

## Run locally

```bash
npm install
npm run dev
```

Dev server: [http://localhost:43127](http://localhost:43127)

## Share with interns

1. Publish the site so it has a public URL.
2. Send each intern only their role path, plus the AI guide.
3. They can Print → Save as PDF, or download the **study guide** Markdown from Files. That ZIP is the learning documents only, not the app source.

Study files live in `content/guides/`.

## What is inside

| Document | Who |
| --- | --- |
| Developer intern path | Software developer interns |
| QA intern path | QA / tester interns |
